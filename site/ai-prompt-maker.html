Formula

The simple prompt structure that works

Start with the outcome, then add the details that would help a capable person do the same job. That usually means the subject, context, constraints, style, output format and how success should be judged.

  1. State the task. Say whether you want an image prompt, video shot, code change, article outline, analysis or finished answer.
  2. Add useful context. Include the product, audience, source material, model type, platform and what should be avoided.
  3. Define the output. Ask for bullets, JSON, a filename, a command, a shot list, a negative prompt or a final rewritten prompt.
  4. Iterate. In Saient, you can run the same idea through local chat, image gen, video gen and the agent without cloud prompts or API keys.
Short prompts are fine for exploration. For repeatable results, use a structured prompt so the model has enough information to obey you.
